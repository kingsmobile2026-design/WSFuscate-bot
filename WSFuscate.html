Output size targets are minimums based on input size and may append inert Luau comments; this increases file size but does not itself increase protection strength. Select Hardened for higher overhead and stronger obfuscation, or Compact for the smallest output. The binding validates standard Luau primitives and derives the VM mask from that contract; it is not a hardware fingerprint, server secret, or cryptographic boundary. VM strings are decoded on demand; the constant cache keeps a masked buffer and scratch buffers are overwritten, although a returned immutable Luau string cannot be securely erased. VM output can be larger and may depend on runtime features. Test generated code in your target Luau environment before using it in production. Use Preflight checks to review complex input and the local test fixture to check tool stability.
